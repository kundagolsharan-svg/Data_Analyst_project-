# Data Analyst Foundations — Week 1 Project

A complete, runnable practice project covering the six core skill areas of a Data
Analyst role: Excel, SQL, Python, Data Cleaning/EDA, Data Visualization, and Statistics.
Every deliverable is built from one shared sample dataset so the numbers agree across
every tool.

## Folder Structure

```
project/
├── data/
│   ├── sales_data_raw.csv        # Synthetic, intentionally messy source data (2,025 rows)
│   ├── sales_data_cleaned.csv    # Cleaned + validated + KPI-ready output (2,018 rows)
│   └── sales_data.db             # SQLite DB (customers / products / orders) for the SQL task
│
├── python/
│   ├── 00_generate_dataset.py            # Builds the raw sample dataset

│   ├── 03_build_excel_dashboard.py       # Builds excel/sales_dashboard.xlsx

│                                          # (Python basics -> cleaning -> KPIs -> EDA -> charts)
│
├── sql/
│   └── queries.sql               # 13 practice queries: SELECT/WHERE, ORDER BY, GROUP BY,
│                                  # HAVING, JOINs, subqueries, window functions — all verified
│                                  # to run against data/sales_data.db
│
├── excel/
│   └── sales_dashboard.xlsx      # 4-sheet workbook: Dashboard, Raw Data, Summary, Lookup Demo

├── eda/
```

## How to reproduce everything from scratch
```bash
cd python
python3 00_generate_dataset.py           # -> data/sales_data_raw.csv
python3 01_data_cleaning_and_eda.py      # -> data/sales_data_cleaned.csv, visuals/*.png
python3 02_build_sql_database.py         # -> data/sales_data.db
python3 03_build_excel_dashboard.py      # -> excel/sales_dashboard.xlsx
```
The notebook (`data_analysis_notebook.ipynb`) reproduces steps 1's analysis interactively,
cell by cell, with Python-fundamentals examples included, and has already been executed —
open it and the outputs (tables, KPIs, charts) are there to read without re-running anything.

## Notes on the data
The dataset is synthetic ("Superstore-style" retail sales), generated by
`python/00_generate_dataset.py` with deliberately injected problems — missing values,
duplicate rows, inconsistent casing, mixed date formats, negative quantities, and a few
outliers — so the data-cleaning task has real work to do. Regenerate it any time for a
fresh (slightly different) practice dataset; the seed is fixed, so a rerun without code
changes reproduces the exact same file.

## Why Power BI is a guide + HTML dashboard, not a `.pbix`
Power BI Desktop only runs on Windows and can't be executed in this environment to
produce a `.pbix` file. `dashboard/business_dashboard.html` is a fully working,
filterable substitute (open it in any browser right now — no installation), and
`dashboard/powerbi_guide.md` gives the exact steps and DAX measures to build the native
Power BI version from `data/sales_data_cleaned.csv` in about 15 minutes.
